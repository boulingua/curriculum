# Unit review record

Copy this record into the course's review ledger. Leave unchecked items and
reviewer fields empty until the work actually occurs.

- Source revision or file digest:
- Reviewer / review date:
- Language competence and native-checker record where required:
- Outcome: pending / changes-required / approved

## Learner and task evidence

- [ ] The stated level and prior knowledge fit the actual input and tasks.
- [ ] All five keyed steps exist, in order, with meaningful learner activity.
- [ ] The Apply task has a communicative result, audience and success criteria.
- [ ] Task inputs are complete in HTML and standalone learner materials.
- [ ] Answers and marking guidance match the tasks, including alternative answers.
- [ ] Differentiation offers useful support and extension without changing the goal.
- [ ] Reflection asks learners for evidence against stated outcomes.
- [ ] Each asserted descriptor has a task/section citation and an explanation of fit.
- [ ] Missing curricular coverage is recorded honestly; proposals remain proposals.

## Assessment and delivery

- [ ] Exactly one canonical sibling exam; the unit contains only its pointer.
- [ ] Duration, points, skills, task maxima and marking guidance agree.
- [ ] Learner PDFs omit keys; teacher versions retain them.
- [ ] Downloadable input, tasks, answer space and page breaks were inspected.
- [ ] Text and examples were checked for accuracy, suitability and inclusion.
- [ ] Source attribution, third-party rights and retained material provenance checked.
- [ ] Audio has a passed review and provenance, or a logged text-first alternative.
- [ ] URL and prior heading anchors remain usable.
- [ ] Counts meet the published band, or the unfinished retrofit is explicitly flagged.

Record actual observations, affected task paths, changes requested and verification
commands. A checked box without evidence is not a review.
